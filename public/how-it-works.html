Cómo funciona ChatLume

ChatLume procesa tus exportaciones de chat en local, dentro de tu navegador. No se sube nada a ningún servidor.

Procesamiento local de archivos

Cuando arrastras un archivo .txt o .zip a ChatLume, se lee con la API File de HTML5. El contenido lo procesa JavaScript que se ejecuta directamente en tu navegador. En ningún momento interviene un servidor ni una API externa.

Modelo de privacidad

Como todo ocurre en local, tus datos están seguros de raíz. Puedes desconectar internet después de cargar la página y la herramienta seguirá procesando y mostrando tu chat sin problema.
